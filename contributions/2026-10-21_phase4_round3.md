## 0. 結果を見る前の手順・計測単位

1. **S0/S1**：`next_queries.py --with-review --json` の未検索 `externalized structured memory agents outperform long-context cumulative exploration efficiency`（keyword）と `externalized structured memory agents survey`（review）を文字列を変えずに検索する。「既存仮説の外側」の coverage は未検索 `self generated text recognition changes task format`（`EVD-20261021-c4d0`）を1件検索する。引用・被引用を辿れた場合は別 QRY に記録し、辿れなければ三系統達成とは言わない。実際に実行した検索のみ QRY とし、ツールの表示件数と抄録確認件数を分ける。
2. **S2（検索前の包含基準）**：タイトルと抄録で、LLM エージェントの外部化記憶／ファイル状態と長文脈・履歴持ち越しの同条件比較、または複数セッションの記録・再現性を観測した一次研究を候補にする。coverage は生成テキストの自己認識を課題／表示形式で比較した一次研究だけを候補にする。既登録の論文は再登録しない。一般論だけのサーベイ、ブログ、対象・比較条件がない論文は新規の支持・反駁として採らない。**独立した二つの選別セッションを用意できない**ため、今回の候補は単一セッションの暫定採否であり、S2 二重選別の完了と称しない。
3. **S3/S4**：新しい出典を採るときは版付き原典の逐語だけを EVD excerpt に置き、課題・モデル・予算・比較群が異なれば `neutral` または `unresolved` とする。既存の未説明 EVD に便宜的な support を付けて穴を減らさない。反証候補を明示的に探し、単独出典の `refute` は provisional のまま扱う。新 REL の独立二重裁定はこの単一セッションでは証明不能なので、比較器の数値や `PRD-20261021-1f70` の正式採点を捏造しない。旧 REL・PRD・凍結ベースは上書きしない。
4. **S5/S6**：既存 HYP の言い換えや二次資料の要約を新仮説にしない。識別的な反証条件・非重複の新しい予測が見当たらなければ HYP=0／PRD=0 と記録する。
5. **S8 の停止判定（実装は非ゲート計測器）**：`unexplained_after >= unexplained_before`、または `refute_before = refute_after = 0` かつ生成元除外後の support が増加、または直近3ラウンドの HYP=0 なら、次ラウンドを起動しない。予算（トークン／人間介入時間）の上限は依頼で未指定なので判定不能と表示し、閾値を後付けしない。欠測を「継続許可」と誤読しない。
6. **自動化率の単位**：§6 の時間ベースは人間の介入時間が不明なので算出しない。回数ベースは**代替の探索的計測**として、実際に記録できた「次の行動または台帳の取捨を変える選択」を1イベントとする（人間の着手承認、検索対象の選択、抄録ごとの採否、採用出典からの抽出の有無、RELごとの verdict、仮説と予測の起票判断、停止判断）。単なる tool call、プレビューのみの未審査候補、「何もしない」が機械的に決まった工程は数えない。人間かエージェントか機械かを集計し、`1 − 人間の判断イベント/全判断イベント` はこの単位に依存する参考値と明示する。ラウンド1・2にこの分母を遡及して作らない。

### 2.2 残る問題と再現

- 二重 S2 / S4 とモデル独立性は現セッションのツールから証明できない。今回の QRY、SRC、EVD、REL は*単一裁定の暫定記録*。裁定一致率は今回の新 REL に対して**未測定**であり、ラウンド2の歴史的 REL の13/20を流用しない。
- 今回の新規出典3本は3つの独立ベンチマークではない（MemoryArena は2本が共有）。EVD のキーは検索種であって独立追試・provisional 解消ではない。負の結果も対象と測定量の違いを理由に neutral にしたが、**refute が世界に存在しないという結論ではない**。
- 版固定 arXiv の書誌を新しい fixture shard に記録した。原典本文の逐語はこの単一エージェントが版付き本文と照合したもので、人間／独立セッションの二重照合ではない。オフライン CI が意味・逐語の正しさや掲載会議を保証するわけではない。ID 18 は凍結のまま。
